プライバシーポリシー

2026年11月25日施行

要点
  • ゲームの進行状況はあなたの端末にのみ保存されます。私たちはサーバーを持たず、受け取ることもありません。
  • アカウントはなく、名前やメールアドレスなどの個人情報をお尋ねすることもありません。
  • 広告は Google AdMob が表示し、広告の配信と効果測定のために端末の一部データを収集します。広告をパーソナライズするかどうかはあなたが選べます。

このポリシーは、モバイルゲーム Gloss Maze（以下「本ゲーム」「私たち」）が情報をどのように扱うかを説明します。Gloss Maze は、Joytap Games の名前でゲームを公開している個人開発者 Narek Sargsyan が制作しています。ご質問は glossmaze.support@gmail.com までお送りください。

端末に保存される情報

続きから遊べるよう、本ゲームはスマホやタブレットに次の情報を保存します：

  • 解放した最高ステージ
  • クリアした各ステージの星の数
  • ゲーム内で獲得したコイン
  • 途中のステージでの手順（後で続きから遊ぶため）
  • 設定：ボールの速度、バイブレーション、言語

これらの情報は端末内にとどまり、私たちや第三者に送信されることはなく、あなたの身元とも結び付けられません。ゲームを削除すると消去されます。

独自の分析ツール、クラッシュレポート、トラッキングツールは使用しておらず、ログインやアカウントもありません。

広告（Google AdMob）

本ゲームは無料で、ステージの合間に表示される全画面広告で運営されています。これらの広告は Google Mobile Ads SDK を通じて Google AdMob が提供します。ここに記載のデータを受け取るのは私たちではなく Google で、その利用は Google プライバシー ポリシーに従います。

Google によると、Google Mobile Ads SDK は広告、分析、不正防止のために次のデータを自動的に収集・共有します：

データ内容
IP アドレスおおよその位置（国や都市など）の推定に使われることがあります。
広告とのやり取り表示された広告と、それをタップしたか閉じたか。
診断起動時間やクラッシュなど、ゲームと広告 SDK の動作に関する技術情報。
端末などの識別子端末の広告識別子（Android の広告 ID、またはトラッキングを許可した場合は Apple の IDFA）と、アプリや端末の類似の識別子。

Google によると、これらのデータは送信時に暗号化されます。詳しくはGoogle のサービスを使用するサイトやアプリから収集した情報の Google による使用をご覧ください。

広告に関するあなたの選択

  • EEA、英国、スイスでは：初回起動時に Google の同意フォームが、広告のパーソナライズにデータを使ってよいかを確認します。回答はいつでもゲームの設定（歯車ボタン）のプライバシー設定から変更できます。
  • iPhone と iPad では：本ゲームは Apple の App Tracking Transparency の確認画面でトラッキングの許可を求めます。Appにトラッキングしないように要求を選ぶと、端末の広告識別子（IDFA）は共有されず、それを使った広告のパーソナライズも行われません。後から 設定 › プライバシーとセキュリティ › トラッキング で変更できます。
  • Android では：広告 ID は端末の 設定 › Google › 広告（端末によっては 設定 › プライバシー › 広告）でリセットまたは削除できます。
  • 共通：Google 広告のパーソナライズはマイ アド センターで管理できます。

同意しなくてもゲームは遊べます。広告は表示されることがありますが、あなたのデータでパーソナライズされることはありません。

お子さまについて

Gloss Maze は全年齢向けのゲームで、13歳未満のお子さまを対象としていません。お子さまの個人情報を意図的に収集することはありません。お子さまがゲームを通じて個人情報を提供したと思われる場合は、ご連絡ください。対応いたします。

あなたの権利

私たちは個人情報を収集・保存していないため、閲覧・訂正・削除の対象となるあなたのデータを保有していません。進行状況はゲームを削除すると消えます。

Google が広告のために収集するデータについては、Google が独立した管理者として扱います。上記の選択肢を使うか、Google プライバシー ポリシーを通じて Google に直接権利を行使できます。お住まいの地域（例：欧州の GDPR やカリフォルニア州の CCPA）によっては、データへのアクセス、削除、処理への異議申し立て、地域のデータ保護当局への苦情申し立ての権利があります。

私たちはあなたの個人情報を販売しません。

このウェブサイト

このサイトは GitHub Pages でホストされています。ホームページの盤面はすべてブラウザ内で動作し、何も保存しません。Cookie、分析、広告は使用しておらず、フォントも第三者ではなくこのサイトから配信しています。GitHub は訪問時に IP アドレスなどの技術情報を記録することがあります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

ポリシーの変更

新しい広告パートナーの追加など、情報の扱いを変更する場合は、このページと冒頭の施行日を更新します。大きな変更はアプリのリリースノートでもお知らせします。
