Maze

Deslize a bola. Ela rola até bater numa parede e pinta cada casa por onde passa. Pinte todas para passar de nível.

Em breve naApp Store Em breve noGoogle Play

Grátis, com um anúncio de vez em quando entre as fases

Esta fase está se resolvendo sozinha. Deslize, arraste ou use as setas para jogar.

Como jogar

  1. Deslize

    Mande a bola para cima, para baixo, para a esquerda ou para a direita. Dá para mudar de direção sem levantar o dedo.

  2. Ela continua rolando

    A bola só para ao bater numa parede, então o desafio é escolher onde parar.

  3. Pinte cada casa

    Cada casa por onde a bola passa fica pintada. Pinte o labirinto inteiro para terminar a fase.

Um labirinto novo a cada vez

Cada fase tem um desenho novo, e todas têm solução. Veja algumas do jogo.

Feito para relaxar

  • Fases infinitasSempre chegam labirintos novos, aos poucos maiores e mais complicados.
  • Sem cronômetro, sem game overLeve o tempo que quiser. Desfazer e recomeçar estão sempre à mão.
  • Estrelas para soluções caprichadasTermine com o menor número de movimentos para ganhar as três estrelas.
  • Anúncios que não atrapalhamSó entre as fases, nunca durante, e nenhum nas cinco primeiras fases.
  • Joga offlineNão precisa de internet para jogar. Os anúncios só aparecem quando você está online.
  • Sem contaSeu progresso fica salvo no celular. Não precisa se cadastrar.
